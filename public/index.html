看看有哪些工具 open-tw on GitHub

專案

每個專案都是獨立的，可以只拿你需要的那一個。

辦公室小幫手

officer-helper

在瀏覽器裡處理辦公室文件，檔案不會上傳。

  • 把網址或文字做成 QR Code
  • 把多個檔案打包成 zip
  • 批次壓縮圖片
  • 舊版 .xls 轉成 .xlsx、.ods、.csv
  • 把 PDF 放大分割成 A4／A3 海報

目前提供原始碼，可以自行建置成靜態網站部署。

查看原始碼 React，MIT 授權

氣象署資料 SDK

@open-tw/cwa-sdk

用 TypeScript 串接中央氣象署開放資料。

不用自己處理請求格式和回應型別。可以查全台 22 縣市各鄉鎮的 3 天與 1 週預報，也附上 368 個鄉鎮的名稱清單方便選地點。

npm install @open-tw/cwa-sdk

使用前需要到中央氣象署開放資料平台申請授權碼（API Key）。地震、觀測與警特報正在規劃中。

查看原始碼 TypeScript，MIT 授權

Lite Wiki

lite-wiki

輕量、可自架的團隊知識庫。

  • 用 Markdown 撰寫，也有所見即所得編輯器
  • 每次儲存都保留版本，可比較兩個版本
  • 用網址表示上下層頁面，自動產生麵包屑
  • 搜尋標題與內容、查看最近變更
  • 別人先儲存時會提示，不會直接覆蓋

目前是 Alpha 版（v0.1.0），適合小團隊自架試用。需要 Node.js 與 PostgreSQL。

查看原始碼 React + Hono，MIT 授權
